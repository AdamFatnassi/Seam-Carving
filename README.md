# Content-Aware Scaling

A project implementing content-aware image resizing using seam carving. The algorithm removes low-energy seams while preserving important visual content.

## Example

![Castle image](castle1-1.png)

## Features

- Energy-map computation
- Vertical seam detection
- Content-aware image resizing
- Preservation of important image regions

## Project Structure

- `castle1-1.png` — Example input image
- Source files — Implementation of the content-aware scaling algorithm

## Usage

1. Open the project in your development environment.
2. Select an input image.
3. Set the desired output dimensions.
4. Run the program to generate the resized image.

## Requirements

Install the dependencies required by the implementation before running the project.
